## 4. 安装、卸载与系统变更

4.1 安装程序会在你的用户目录中写入以下内容：

- `%LOCALAPPDATA%\Programs\CursorComet`：程序文件；
- 开始菜单快捷方式；如果你勾选，也会创建桌面快捷方式；
- `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\CursorComet`：卸载信息；
- `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\MouseTrail`：仅当你勾选“开机自动启动”时写入。

4.2 配置文件和错误日志保存在 `%APPDATA%\MouseTrail`。错误日志可能包含异常堆栈和本地文件路径，仅保存在你的电脑上。

4.3 卸载程序会删除程序文件、快捷方式和卸载项，并移除安装时写入的开机启动项。配置文件默认保留；如需一并删除，请手动删除 `%APPDATA%\MouseTrail`。

4.4 安装和卸载不需要管理员权限。安装或升级时，安装程序可能会关闭正在运行的 Cursor Comet。你可以在 Windows“设置 → 应用”中卸载本软件。
